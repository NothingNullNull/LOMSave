# 一键包第三方组件

一键包使用未经修改的 [BepInEx 6.0.0-be.692 Unity Mono Windows x64 官方构建](https://builds.bepinex.dev/projects/bepinex_be/692/BepInEx-Unity.Mono-win-x64-6.0.0-be.692%2B851521c.zip)。官方 ZIP 的 SHA-256 为 `9a3472f5eefb35a84ae8c6dea16814b728aff807c67c14fbfd448e20112951a6`。

本包保留以下组件的许可说明，位于 `LOMSave2说明/第三方许可/`，随整合包一起解压：

- BepInEx 6.0.0-be.692：[源码](https://github.com/BepInEx/BepInEx/tree/851521cc126e4f9d841d2d9bfe857558f0395939)，LGPL 2.1；对应源码压缩包为 `LOMSave2说明/第三方源码/BepInEx-6.0.0-be.692-source.zip`。
- UnityDoorstop 4.3.0：[源码](https://github.com/NeighTools/UnityDoorstop/tree/d061d7eabe9fc36140e7239955515801e2b9db12)，LGPL 2.1；对应源码压缩包为 `LOMSave2说明/第三方源码/UnityDoorstop-4.3.0-source.zip`。
- HarmonyX 2.10.1：[源码](https://github.com/BepInEx/HarmonyX/tree/v2.10.1)，MIT。
- MonoMod 22.5.1.1：[源码](https://github.com/MonoMod/MonoMod/tree/v22.05.01.01)，MIT。
- Mono.Cecil 0.10.4：[源码](https://github.com/jbevain/cecil/tree/98ec890d44643ad88d573e97be0e120435eda732)，MIT。
- AssetRipper.Primitives 3.1.1：[源码](https://github.com/AssetRipper/AssetRipper.Primitives/tree/2e8940973fe58184b259ba9959b1359d87fce790)，MIT；随附其第三方许可。
- SemanticVersioning 2.0.2：[源码](https://github.com/adamreeve/semver.net/tree/2.0.2)，MIT。

组件版权归各原作者所有。第三方程序及其源码沿用各自许可，与 LOMSave 独立；未把游戏专有程序集纳入本包。

本包不包含骰子大师。共存验证所用的第三方插件样本仅用于本地测试。
