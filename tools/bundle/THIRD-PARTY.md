# 一键包第三方组件

一键包使用未经修改的 [BepInEx 5.4.23.5 Windows x64 官方发行包](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5)。官方 ZIP 的 SHA-256 为 `82f9878551030f54657792c0740d9d51a09500eeae1fba21106b0c441e6732c4`。

本包保留以下组件的许可说明，位于 `LOMSave2说明/第三方许可/`，随整合包一起解压：

- BepInEx 5.4.23.5：[源码](https://github.com/BepInEx/BepInEx/tree/v5.4.23.5)，MIT。
- UnityDoorstop 4.5.0：[源码](https://github.com/NeighTools/UnityDoorstop/tree/33dab9a6733862eb81869ff08431d9478b28784b)，LGPL 2.1；对应源码压缩包放在 `LOMSave2说明/第三方源码/UnityDoorstop-4.5.0-source.zip`。
- HarmonyX 2.7.0：[源码](https://github.com/BepInEx/HarmonyX/tree/253725768e59b0e1ea90105cdbcc4a0a477422c7)，MIT。
- MonoMod v21.12.13.01：[源码](https://github.com/MonoMod/MonoMod/tree/ede81f48924d58abf05359409fad740fe2b0dfb5)，MIT。
- Mono.Cecil 0.10.4：[源码](https://github.com/jbevain/cecil/tree/98ec890d44643ad88d573e97be0e120435eda732)，MIT。
