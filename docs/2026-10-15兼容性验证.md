# 2026-10-15 游戏更新兼容性验证

本页保留首轮验证结果与当时 DLL 的校验值。随后按用户要求调整了 `FreeRandomState` 排除及警告规则，当前行为以 [存读档状态验证](存读档状态验证.md) 为准，以下历史 `DIFF` 数量不代表新规则的计数。

结论：2.0.2 本地修复版通过本次自动检查及游戏内专项测试；新版存读档样本有条件通过，仍保留已知四项随机状态差异。跨版本旧剧情档不能一概判定为精确兼容。本次未发布 GitHub Release。

修复了三处问题：

1. 游戏程序和 Mono 已为 x64，原 `winhttp.dll` 仍为 x86，MOD 无法被加载。改用同版本官方 x64 加载器；核心托管文件与旧包逐个比对一致。下载包校验值与 [官方发布](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5) 的 SHA-256 一致：`82f9878551030f54657792c0740d9d51a09500eeae1fba21106b0c441e6732c4`。
2. 人物介绍新增 `Show(string, int)`，旧补丁出现方法歧义。现在明确绑定双参数方法，单参数委托只记录一次；模式 0 激活关系，模式 1 仅展示介绍，旧事件键保持可读。
3. 命运确认新增旗标 `Z00002`，记录六项基础属性相对默认值的加成总和。现在捕获该结果并校验回放值；旧格式 4 事件缺少该字段时按新版规则计算。

## 跨版本差异与未测项目

旧样本与更新前保存的快照之间有 555 项差异，报告完整保留。多数涉及新增或移除的数据项和集合数量，包括技能、任务、事件标记、角色、时间数据及装备；另有游戏版本、随机状态、起始脚本和空键任务条目的名称变化。当前剧情脚本与对话等待位置一致，但不能据此宣布后续任务路线全部不变。起始脚本及任务变化未逐条验证后续剧情。

静态剧情比较中，225 个脚本的相关事件调用序列发生变化；存在删除脚本、拆分剧情和文本改写。同名资源还有简体、繁体副本，旧单文件资料不能代表每种语言。某个旧样本回放成功不等于所有旧档兼容，重新保存后的四项随机差异也不能反向证明原旧档完全恢复正确。

格式 2 回退、格式 3 读取与人工补录入口通过自动检查；本次未重新完成格式 3 的整段游戏内人工回放。战斗、掷骰、结局、新增完整剧情路线、装备临时替换/还原、多语言和其他 MOD 共存未逐项实测。

本次没有隐藏差异、修改原存档或发布新版本。详细执行步骤继续使用 [游戏更新兼容性检查清单](../游戏更新兼容性检查清单.md)。
