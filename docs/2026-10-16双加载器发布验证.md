# 2.0.4 双加载器发布验证

同一套源码分别构建 BepInEx 5 / 6，存档与回放逻辑共用。差异限于加载器引用、插件和快捷键命名空间，以及各自的构建、打包配置。

## 基线

- 游戏：`release_1.0.6000.2`，Steam Build 25957922，Unity 2020.3.49f1，Windows x64 Mono。
- BepInEx 5：官方 `5.4.23.5` Windows x64。
- BepInEx 6：官方 `6.0.0-be.692+851521cc126e4f9d841d2d9bfe857558f0395939`，Unity Mono Windows x64。
- MOD：2.0.4；两种构建的程序集均为 `LOMSave2, Version=0.0.0.0`，插件 GUID、配置项、附加档格式 4 及格式 3 读取能力不变。
- 骰子大师样本及来源、哈希见 [BepInEx 6 迁移验证](2026-10-16BepInEx6迁移验证.md)，不将该样本视作所有渠道的最新版，也不随发布包分发。

实机测试使用独立游戏副本，存档、传奇和备份路径重定向到测试目录，测试辅助插件阻止设置及成就写入。F5/F8/F9 通过窗口键盘输入触发，未以反射调用替代这些按键；辅助插件负责等待、断言与结果记录。状态界面、骰子操作和反向互读的最后一轮由测试辅助代码调用实际游戏入口。

首轮测试环境准备时，插件目标目录尚不存在，复制命令误将 DLL 写成名为 `plugins` 的文件，加载器因此启动失败。纠正测试目录后重跑通过；该问题不在正式包中，正式包结构另经解压测试验证。

## 发布与维护

- 一套源码、一个版本号，分别输出 `BepInEx5` / `BepInEx6` 标识的普通包、一键解压包和独立 DLL。
- 一键包包含对应官方加载器；普通包只包含 MOD 与说明。两种构建只能选一个安装。
- 构建工具自动下载并校验两套固定版本的依赖，不需要为开发各维护一份源码。
- 游戏更新后，两种构建分别执行自动检查和实机存读档；涉及依赖、输入、Harmony 或第三方插件时，另测对应加载器及共存组合。

## 限制

- `PASS` 按现有规则忽略时间戳和 `FreeRandomState`，不代表全部内存或后续随机结果相同。
- 此次实机样本覆盖 71 个事件的旧档、重新保存和双向互读，不覆盖全部剧情停点与所有跨游戏版本旧档。
- 未验证其他 BepInEx 6 构建、IL2CPP、所有第三方插件或骰子大师所有功能。原有异常回放检查与限制见此前验证记录。
- 具体安装、切换加载器及回退步骤见 [README](../README.md)；不能混用 5/6 核心文件，也不能仅修改 `target_assembly`。
